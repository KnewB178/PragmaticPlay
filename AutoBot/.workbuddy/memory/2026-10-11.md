环境：Windows 11，项目 `C:\Users\user\Desktop\PP AutoBot`（路径含空格），无 venv。

### 根因 1（用户实际看到的报错）
- 该目录**没有 venv 文件夹**（从 macOS 同步过来，venv 是平台相关的所以没带上；目录里还留着 `._*` 与 `.*.baiduyun.uploading.cfg` 同步中间文件）。

### 根因 2（main.py 自身 bug，已修）
- `main.py` 的「自动切到 venv python」用 `os.execv()`；**Windows 下 os.execv 不给路径加引号**，
  项目路径 `PP AutoBot` 含空格 → 命令行被解析成 `C:\Users\user\Desktop\PP` + 余下部分 →
  报 `can't open file '...\AutoBot\venv\Scripts\python.exe': [Errno 2]`。
- 已用对照实验证实：execv 到**无空格**路径正常，execv 到**带空格**路径必崩。
- **修复**：`main.py` 第 68-70 行附近，把 `os.execv(...)` 换成
  `sys.exit(subprocess.call([str(_venv_py)] + sys.argv))`（list2cmdline 自动加引号）。
  修复后模拟双击可正常切到 venv python。

### 未决：原生模块被「应用程序控制策略」拦截
- 在 venv 里 `import numpy` / `from Crypto.Cipher import AES` 均失败：
